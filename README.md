## Como instalar

**Windows** — abra o arquivo baixado. Se aparecer *"O Windows protegeu o computador"*, clique em
**Mais informações** → **Executar assim mesmo**. Não precisa ser administrador.

**Mac** — abra o `.dmg` e arraste o app para Aplicativos (o Instalador pode ser aberto direto do `.dmg`).
Na primeira vez, clique com o **botão direito** no app → **Abrir** → **Abrir**.

Depois é só entrar com o mesmo e-mail e senha do portal WCAM.

## Versões

Todas as versões estão em [Releases](https://github.com/Jhonata-php/wcam-desktop/releases). O app instalado
confere sozinho se há versão nova ao abrir e a cada 6 horas.
